Active successor entrypoints/runtime reject v0 delivery receipts, `isolatedDogfood`, and every non-host-witness constructor path; no active v0 constructor authority is preserved. Context and contained objects never embed duplicate bodies. Validator decodes and recomputes every length/domain/digest rather than trusting rows. Missing/duplicate/unreachable data rejects. In both exact resolver contexts, every named artifact role other than the out-of-band `resolver_artifact_set_digest` is encoded as its `sha256:` object/blob digest (or ordered array of such digests), not an embedded body; booleans/integers/null remain scalar. The artifact set resolves those references. `resolver_artifact_set_digest` is verified from the out-of-band set before any traversal.

Complete precedence is `malformed_input -> unsupported_protocol -> resource_exhausted -> deadline_exceeded -> digest_mismatch -> issuer_scope_violation -> self_certification -> trust_revoked -> trust_reference_stale -> activation_not_current -> authorization_or_replay_failure -> delivery_relation_failure`. After earlier classes, evaluate all trust facts: any applicable authenticated revocation at/before action epoch is `trust_revoked`; otherwise absent/expired/superseded/non-current/headless evidence is stale. Revoked wins when both; a stale head cannot prove non-revocation. Host/component/controller self-appointment/control is earlier `self_certification`. Validators collect every determinable fault within bounded reads and choose the earliest class in this list, independent of detection order. The sole exception is a deadline equality/expiry observed at a required monotonic guard before a later read can establish resource exhaustion; that guard returns `deadline_exceeded` and performs no later read. If both faults are already established at one guard, `resource_exhausted` wins. V0 historical commands accept v0; successor entrypoints reject v0. Schema-checked v0 objects never substitute for the v0 authority verifier.

## Packet and deterministic implementation limits

Preserve `docs/project/semantic-release-v0/**` byte-for-byte. `docs/project/semantic-pi-delivery-v1/` contains only `packet-manifest.json` plus listed regular files. The strict JCS manifest is exactly `{schema,protocol_revision,files,packet_aggregate_digest,packet_manifest_digest}` with schema `semantic-release.pi-delivery-packet-manifest.v1` and revision `semantic-pi-delivery-v1-r17`. Rows are path-byte-sorted exact `{path,byte_length,sha256}`; SHA is 64 lowercase unprefixed hex of exact bytes. Paths are NFC safe POSIX relative paths with no tab/CR/LF/backslash/empty/dot/traversal/leading/trailing slash. Inventory equality is exact. Aggregate bytes are `path<TAB>canonical-decimal-length<TAB>sha256<LF>`; digest is the registered domain plus NUL plus concatenated rows. Manifest object digest omits only itself.

Packet-required `v0-baseline-manifest.json` is exactly `{schema,decision_id,accepted_decision_record_digest,files,v0_baseline_aggregate_digest,v0_baseline_manifest_digest}` with decision `53`; rows cover the complete accepted `semantic-release-v0/**` inventory under the same encoding and dedicated v0 baseline aggregate domain. Its literal accepted Decision 53 digest, rows, aggregate, and self-digest are generated once from accepted bytes and its raw file hash is pinned by the r17 packet. Validators compare current v0 bytes and non-Pi overlay roles/edges/properties/precedence/currentness to this pinned baseline; recomputing a changed baseline cannot make it accepted.

Outside the packet, `semantic-release.pi-delivery-packet-acceptance.v1` is exactly `{schema,decision_id,rfc_revision,packet_manifest_digest,v0_baseline_manifest_digest,accepted_decision53_record_digest,accepted_at_utc,statement_digest,signing_key_id,signature_algorithm,signature,packet_acceptance_digest}`. Decision is `71`, revision `semantic-pi-delivery-v1-r17`; the current semantic protocol owner resolved by the v0 authority proof signs with `packet_acceptance` purpose, publishes it in its authenticated store, and supplies current control/pin/read evidence. Production and integration contexts require exact manifest/baseline/Decision-53 joins; a substituted self-consistent packet cannot acquire acceptance.

Packet-required `protocol-registry.json` is exactly `{schema,protocol_revision,schemas,domains,edges,packet_bindings,entrypoints,protocol_registry_digest}`. Schema rows are UTF-8-name-sorted unique `{schema_name,file_path,schema_digest}`; `schema_digest` uses `semantic-release.pi-schema-file-bytes.v1` over exact schema bytes, while the same file's packet row `sha256` equals ordinary lowercase SHA-256 of those bytes; both are recomputed and cross-checked. domain rows are ASCII-domain-sorted unique `{object_name,domain,self_digest_field_or_null,preimage_kind}`; edge rows are sorted/unique by `(source_schema,field_pointer,edge_kind,discriminator_value_or_null)` and exactly `{source_schema,field_pointer,edge_kind,target_schema_or_null,target_domain_or_null,cardinality,discriminator_pointer_or_null,discriminator_value_or_null}`. Edge kind is `object|blob|non_edge`, cardinality `one|nullable|array`; pointers are canonical RFC6901 with `*` denoting one array-element step. Every digest-shaped field in every schema has exactly one exhaustive discriminator row: self/derived/history-head values are `non_edge`, while artifact edges name one target schema/domain. Packet bindings are path-sorted unique `{file_path,schema_name,schema_digest}` and equal schema rows. entrypoints are the exact sorted set `integration_resolver,module_closure,packet,production_resolver`. Registry inventory equals every schema/domain named by the packet and these annexes. `protocol.schema.json` top-level `oneOf` is derived by sorted schema rows exactly; missing/extra/reordered inventory rejects.

Limits and the single monotonic deadline start before the first packet/archive/executable/ledger read and end only after process reap, filesystem recheck, transcript/ledger terminal persistence, and receipt/proof validation. They include packet files, compressed/extracted archives, standalone host/controller executable bytes, stdout/stderr, disposable outputs, pre-redemption journals, and all ledger reads/growth:

- 16 MiB per JSON file, 64 MiB packet aggregate, 32 packet files;
- 64 MiB compressed tarballs cumulative;
- 512 MiB extracted component + all dependencies + host cumulative;
- 4096 total extracted files, 128 dependencies, 4096-byte logical paths;
- JSON depth 64, arrays at most 100,000 unless lower field cap;
- one 60,000 ms monotonic deadline; equality expires;
- retained-byte accounting once per object; no reopen;
- stable no-follow regular-file reads, descriptor/path identity/metadata checks;
- NFC root-local POSIX paths; no traversal, backslash, network form, symlink, hard link, special file, normalization/casefold collision;
- extraction ratio at most 32:1 per archive and cumulatively;
- standalone host + runtime-data + controller executable/manifests at most 128 MiB cumulative;
- stdout and stderr at most 1 MiB each; disposable output at most 64 MiB;
- pre-redemption journal at most 1 MiB; canonical ledger at most 64 MiB and 100,000 records, with the current operation accounting every read/new byte.

Error codes and precedence are generated and independently tested. Detection order never overrides the complete-fault-set order; only the explicitly defined pre-read deadline guard can stop before a resource fact exists.
