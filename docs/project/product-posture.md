# Product Posture: rocs-cli

## Posture in one sentence

`rocs-cli` is a mature, deterministic, offline-first validator and transport for ROCS semantic artifacts; its current priority is preserving contract truth and adoption reliability without inventing controlled meaning or becoming a planning authority.

## Current posture

- Workspace-only reference resolution and local validation are implemented.
- Bootstrap, audit, safety, and transaction helpers have direct test coverage.
- The previous helper-convergence implementation wave is complete.
- AK-native `SF1` remains the strategic frame; there is no active implementation wave or ready repo task.

## Target operator experience

1. Operators invoke one small local CLI with deterministic output.
2. Layered artifacts resolve from explicit workspace-owned inputs without remote fallback.
3. Validation explains structural or semantic-contract failures without authoring new ontology meaning.
4. Live direction and execution are read from AK rather than Markdown planning ladders.

## Current gaps

- Keep docs, generated helpers, and downstream adoption surfaces aligned with shipped behavior.
- Strengthen evidence links only when authoritative task or decision identities exist.
- Avoid speculative command growth while existing contracts remain sufficient.
