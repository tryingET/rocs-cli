# Evidence note — semantic Pi insertion evidence v1

## Accepted identity

Pi-owner evidence `5030` and `5031` establishes:

- repository: `pi-extensions`;
- component: `pi-ontology-workflows`;
- package: `@tryinget/pi-ontology-workflows`;
- accepted identity commit: `63d1e9f5c271007b48c45818d1f419a228de1561`.

It rejects `pi-adapter` as a product/repository alias and grants no implementation or live authority.

## Host seam

Observed Pi behavior chains `before_agent_start` results and later assigns the resulting system prompt to host state. A contributor callback return occurs before assignment and cannot prove insertion. The required seam is therefore post-assignment/readback and host-owned. A host-private object can prove same-process issuance without claiming that a serialized digest is public authority.

## Failed broad direction

- Decision 71/r21 task `4230`, evidence `5325`: pinned Unicode source contradiction.
- Decision 80/r23 task `4250`, evidence `5404`: undefined `preimage_kind` vocabulary.
- Decision 82/r24 task `4278`, evidence `5446`: schema/edge/fixture compiler underdetermination and passing-proxy implementation.
- Decision 84/r25 task `4298`, evidence `5492`: exhaustive correction requires at least 155 schemas and 2,591 root properties before nested shapes; four catalog attempts were inconsistent and non-machine-executable.

These are observed failures, not permission to infer missing bytes.

## Scope-reduction evidence

The useful observable is much smaller than the failed protocol:

1. exact input prompt digest;
2. exact component contribution digest;
3. exact assigned prompt-chain digest;
4. exact host readback digest equal to the assigned digest;
5. host execution generation, attempt ID, and handler index;
6. one-use host-private witness consumed by the same registered contributor;
7. a final host record created before provider/model dispatch becomes eligible.

None of these facts requires a production authority graph, generic artifact resolver, SQL ledger, recovery process, seccomp compiler, WebAssembly loader, consumer owner, or semantic publication overlay.

## Authority boundary

A live branded witness is same-process capability evidence. Persisted JSON is deterministic audit data only; absent a separately reviewed host-owner trust root, it is not independently authenticated public proof. Passing fixtures cannot convert it into semantic delivery or production authority.

## Legal next move

Decision 85 may proceed to exact-byte strict review. Only a converged review and accepted superseding ADR may authorize fresh, owner-scoped implementation planning. No predecessor downstream task is reusable.
